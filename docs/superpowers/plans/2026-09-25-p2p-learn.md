# P2P Learn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a web app where peers book 1-hour lessons using a time ledger (teach to earn, learn to spend), with a Jitsi join URL created at booking time.

**Architecture:** NestJS REST API owns PostgreSQL rows and moves hours only inside database transactions. Angular talks over JWT; NgRx feature states (`@ngrx/entity` + effects) update only after a successful response. Meetings are Jitsi URLs, not a custom WebRTC stack.

**Tech Stack:** PostgreSQL 16, NestJS 10, TypeORM, Passport JWT, bcrypt, class-validator; Angular 19 standalone, RxJS, NgRx Store/Entity/Effects; Jest (API); Karma/Jasmine (Angular).

## Global Constraints

- Currency unit is always 1 hour (60 minutes); slot `startAt` must be on the UTC hour (minutes/seconds/ms = 0).
- One `ledger_entries` row with `type='starter'` and **`amount=3`** per user, inserted when the first offering is published. Book/cancel rows use `amount` **±1**.
- Balance = `SUM(ledger_entries.amount)`; the client never PATCHes a balance.
- Every user must keep ≥ 1 offering. `OFFERING_REQUIRED` (403) until then, except: `POST /auth/register`, `POST /auth/login`, `GET /health`, `GET /me`, `PATCH /me`, `POST /offerings`.
- Book: lock slot, `spend -1` learner, `earn +1` teacher, slot `booked`, persist Jitsi URL — one transaction. Empty join URL rolls the transaction back.
- Teacher-only cancel before start: slot becomes `cancelled` (not reopened); `refund +1` learner, `reversal -1` teacher.
- Join URL: `https://meet.jit.si/p2plearn-{uuid}`. Join UI from start−10m through start+60m if booking `confirmed`.
- Error JSON: `{ "code": "<CODE>", "message": "<human>" }` with 4xx. Codes: `UNAUTHENTICATED`, `OFFERING_REQUIRED`, `SLOT_GONE`, `SLOT_IN_PAST`, `SLOT_OVERLAP`, `SLOT_INVALID`, `INSUFFICIENT_HOURS`, `SELF_BOOK`, `FORBIDDEN`, `CANCEL_NOT_ALLOWED`, plus `EMAIL_TAKEN` (409) for duplicate register (not in the original spec list; do not reuse `FORBIDDEN` for this).
- No chat, community, websockets, payments, file uploads, or homemade SFU.
- Angular store updates after API success only — no optimistic ledger writes.
- Spec: `docs/superpowers/specs/2026-09-25-p2p-learn-design.md`.
- Database is **local PostgreSQL** on `localhost:5432`, database `p2p_learn`, user/password `p2p`/`p2p`. Do **not** use Docker.

`api/src/common/http-exception.filter.ts`:

```typescript
import {
  ArgumentsHost,
  Catch,
  ExceptionFilter,
  HttpException,
  HttpStatus,
} from '@nestjs/common';
import { Response } from 'express';
import { AppError } from './app-error';

@Catch()
export class HttpErrorFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost): void {
    const res = host.switchToHttp().getResponse<Response>();
    if (exception instanceof AppError) {
      res.status(exception.httpStatus).json({
        code: exception.code,
        message: exception.message,
      });
      return;
    }
    if (exception instanceof HttpException) {
      const status = exception.getStatus();
      const body = exception.getResponse();
      const message =
        typeof body === 'string'
          ? body
          : ((body as { message?: string | string[] }).message ?? exception.message);
      const text = Array.isArray(message) ? message.join(', ') : message;
      res.status(status).json({
        code: status === 401 ? 'UNAUTHENTICATED' : 'FORBIDDEN',
        message: text,
      });
      return;
    }
    res.status(HttpStatus.INTERNAL_SERVER_ERROR).json({
      code: 'INTERNAL',
      message: 'Try again.',
    });
  }
}
```
